
# Simple Auth Test

This project is a React application built with Vite and TanStack Router.

## Routing

This application uses **Code-Based Routing** with TanStack Router.
Routes are manually defined in `src/main.tsx`.

### Adding a new page

1. Create your page component in `src/pages/`.
2. Import it in `src/main.tsx`.
3. Create a new route using `createRoute` and add it to the `routeTree` array.

## Scripts

- `npm run dev`: Start the development server
- `npm run build`: Build for production
